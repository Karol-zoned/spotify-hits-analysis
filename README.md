"## Spotify Hits Analysis" 

“This project serves as an exploratory data analysis (EDA) exercise focused on developing data analysis and visualization skills.”

#Dataset  
This project uses the spotify_alltime_songs dataset, which contains information on the 100 most streamed songs on Spotify. The dataset includes features such as song title, artist, release year, genre, and other track-level attributes.
The data was sourced from Kaggle:
https://www.kaggle.com/datasets/emanfatima2/spotify-global-hits-and-artist-analytics

#Objective
The goal of this analysis is to identify patterns and characteristics associated with highly streamed songs on Spotify. By exploring factors such as genre, release period, and explicit content, the analysis aims to understand what features are commonly present among top-performing tracks.

It is important to note that the dataset represents a limited sample (top 100 songs), so findings should be interpreted as indicative patterns, not guaranteeing success.
